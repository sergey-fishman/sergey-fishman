# Hi there 👋

My name is Sergey Fishman. I am a student QA engineer working with both manual and automated testing.

## What I do

- **Manual testing:** requirements analysis, test planning, checklists, test cases and test data (Equivalence Partitioning, Boundary Value Analysis, error guessing, exploratory testing), bug reports.
- **API testing:** Postman collections with positive (happy), destructive and negative data validation paths.
- **Test automation:** Java, Selenium WebDriver, TestNG, Gradle; data-driven tests, cross-browser smoke tests, logging.
- **Databases:** SQL.
- **CI and tools:** GitHub Actions, Jenkins, Jira, Chrome DevTools, Git.
